The Opportunity

One content graph. A smarter editorial operation.

TPG sits on a uniquely structured data asset — card reviews, award valuations, affiliate metadata, freshness signals — that no general-purpose AI can replicate. The opportunity is to expose that graph as an intelligent internal tooling layer rather than letting editors manage content staleness manually.

These prototypes share a single thesis: Sanity's Content Lake as the source of truth, with Claude providing the reasoning layer on top. Each prototype targets a different moment in the editorial workflow, but all draw from the same structured schema and GROQ pipeline.

Sanity as connective tissue
🕐Content freshness fields in the Sanity schema feed both the dashboard priority queue and the CLI audit commands — same GROQ query, two surfaces
🤖Agent Context (MCP) provides read-only, schema-aware API access — the right RAG surface for the in-article Claude assistant
⚡Sanity Functions automate valuation change detection and affiliate link checking — surfacing the right articles in the dashboard without editor intervention
🔧sanity exec enables the CLI prototype — custom Node.js scripts running against Content Lake with full Sanity client access

Technical Foundation

Why these prototypes are only possible with Sanity

TPG's migration to Sanity isn't just a CMS swap — it's the infrastructure bet that makes intelligent internal tooling possible. Sanity's structured schema, GROQ query language, and first-class AI integrations provide exactly the platform surface needed without building a bespoke data pipeline for each tool.

The dashboard, CLI, and chat panel are all thin on their own. The product leverage comes from the shared content graph underneath — one schema update propagates everywhere.

Agent Context (MCP)GA · AI Integration
Read-only, schema-aware API surface for Claude — powers the chat panel's context assembly without exposing drafts or write access
GROQ + pt::text()GA · Data Layer
Graph-relational queries with Portable Text extraction — the dashboard and CLI share the same freshness audit query
Sanity FunctionsExperimental · Automation
Event-triggered TypeScript serverless: valuation change detection, affiliate link checking, freshness scoring on publish
sanity execGA · Developer Tool
CLI extensibility for custom Node.js scripts — enables the tpg cms audit / enrich / draft commands with full Content Lake access
