The Opportunity

One content graph. Many AI surfaces.

TPG sits on a uniquely structured data asset — card reviews, award valuations, transfer partner graphs, affiliate metadata — that no general-purpose AI can replicate. The opportunity is to expose that graph as an intelligent product layer rather than letting it sit as flat editorial copy.

These prototypes share a single thesis: Sanity's Content Lake as the source of truth, with Claude providing the reasoning layer on top. Each prototype represents a different surface — reader-facing, internal tooling, and editorial workflow — but all draw from the same structured schema.

Sanity as connective tissue
🗃️Card catalog powers the recommender engine, affiliate CTAs, and the chat panel's context assembly
📊TPG valuations dataset drives the ¢/pt calculations in the portfolio tracker and award search overlay
🕐Content freshness fields feed both the dashboard priority queue and the CLI audit commands
🤖Sanity Agent Context provides read-only, schema-aware API access — the right RAG surface for Claude

Technical Foundation

Why Sanity powers all six prototypes

TPG's migration to Sanity isn't just a CMS swap — it's the infrastructure bet that makes all of this possible. Sanity's structured schema, GROQ query language, and first-class AI integrations (Agent Context, Sanity Functions, MCP server) provide exactly the platform surface needed to build these experiences without a bespoke data pipeline for each one.

The prototypes are deliberately thin on their own — the real product leverage comes from the shared content graph underneath.

Read-only, schema-aware API surface for Claude RAG — used in the chat panel and CLI enrichment commands
